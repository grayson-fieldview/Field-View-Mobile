Replace the current api.uploadPhoto function in artifacts/mobile/services/api.ts with proper API client methods that match the real backend contract for the photo upload pipeline. The pipeline is a 3-step presigned-URL flow:

POST /api/uploads/sign — request presigned S3 PUT URLs for N files
PUT to S3 — upload file bytes directly to the presigned URL
POST /api/projects/:id/media — record media metadata in the database

Backend contract details (verified against the live backend):
Step 1: POST /api/uploads/sign

Auth: session cookie (existing pattern)
Request body shape:
ts{
  files: Array<{
    originalName: string;  // e.g. "IMG_1234.jpeg"
    mimeType: string;      // e.g. "image/jpeg"
    fileSize: number;      // bytes
  }>
}

Validation: 1-20 files per request. Allowed MIME prefixes: image/* or video/*. Allowed extensions: jpg, jpeg, png, gif, webp, mp4, mov, avi, heic. Max image size 50MB, max video size 500MB.
Response shape (200):
tsArray<{
  key: string;        // e.g. "photos/1777408888566-3a1b2c4d5e6f7890.jpeg"
  uploadUrl: string;  // signed S3 PUT URL, expires in 10 minutes
  publicUrl: string;  // permanent CloudFront URL
}>

Order matches the order of input files (1:1 mapping must be preserved).

Step 2: PUT to uploadUrl

Method: PUT
Headers: Content-Type (must match the mimeType passed to /sign), Content-Length (must match the fileSize passed to /sign)
Body: raw file bytes
On success: 200 (no body)
On expired URL: 403 with SignatureDoesNotMatch in body — this is the signal to re-request sign URL and retry

Step 3: POST /api/projects/:projectId/media

Auth: session cookie
Request body shape:
ts{
  files: Array<{
    key: string;            // from sign step
    publicUrl: string;      // from sign step
    originalName: string;
    mimeType: string;
    latitude?: number;      // optional, per-file GPS
    longitude?: number;     // optional, per-file GPS
  }>;
  caption?: string | null;  // optional, applied to whole batch
  tags?: string[];          // optional, applied to whole batch
}

Response (201): array of created Media records:
tsArray<{
  id: number;
  projectId: number;
  uploadedById: string | null;
  filename: string;
  originalName: string;
  mimeType: string;
  url: string;
  caption: string | null;
  latitude: number | null;
  longitude: number | null;
  tags: string[];
  createdAt: string;
}>
