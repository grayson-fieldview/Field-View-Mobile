Visual bug on the projects list (artifacts/mobile/app/(tabs)/index.tsx).

When user navigates back from a project detail screen to the projects
list, all projects DO load correctly (the upstream wipe bug is fixed),
but there's a brief empty gap at the top of the FlatList that looks
like a refresh indicator gap. It feels glitchy.

Likely cause: useFocusEffect → refresh() fires every focus, which
flips DataContext.syncing to true briefly, which is bound to the
FlatList's `refreshing` prop, causing iOS to render space for a
RefreshControl spinner even when no actual fetch is happening (because
of the 4s throttle).
