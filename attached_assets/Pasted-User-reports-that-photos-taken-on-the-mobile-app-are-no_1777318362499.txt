User reports that photos taken on the mobile app are not appearing on the web app for the same project. Need to diagnose where the upload pipeline is breaking. The expected flow is:

User taps the camera/capture button on mobile
Photo is captured (or selected from library)
Photo is uploaded to AWS S3 (via the backend's signed-URL endpoint or direct API)
A photo record is created in the database, associated with the project and account
The photo URL (CloudFront-fronted) is stored in the database
When the web app loads the project, the photo appears in the project's media[]

Do not fix anything yet — diagnose first. I want to understand where in the pipeline things break before deciding on a fix.
