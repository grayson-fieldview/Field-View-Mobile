Install Sentry for error tracking on the React Native mobile app. This is a production error monitoring tool.

Steps:

1. Install the Sentry SDK for Expo:
   npx expo install @sentry/react-native

Note: we use the Expo install command (not npm) because Sentry has an Expo config plugin that needs to register properly.

2. In app.json (or app.config.js if you have one), add the Sentry plugin. Inside the "expo" object, find the "plugins" array (create one if it doesn't exist) and add "@sentry/react-native/expo":

"plugins": [
  "@sentry/react-native/expo",
  // ... any other existing plugins
]

3. Create a new file at services/sentry.ts with this content:

import * as Sentry from "@sentry/react-native";

const DSN = process.env.EXPO_PUBLIC_SENTRY_DSN;

export function initSentry() {
  if (!DSN) {
    console.warn("[sentry] EXPO_PUBLIC_SENTRY_DSN not set — Sentry disabled");
    return;
  }
  Sentry.init({
    dsn: DSN,
    environment: __DEV__ ? "development" : "production",
    tracesSampleRate: 0.1,
    enableAutoSessionTracking: true,
    // We'll opt into session replay later if we decide we want it
  });
  console.log("[sentry] initialized");
}

export { Sentry };

4. In the app entry file (likely app/_layout.tsx), import and call initSentry() at the very top of the file, BEFORE any component code:

import { initSentry } from "../services/sentry";
initSentry();

// ... rest of existing file

6. Restart Expo so the new env var is picked up and the Sentry plugin registers.
